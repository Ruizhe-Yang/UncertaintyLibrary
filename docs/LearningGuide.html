01

学习目标与阅读路线Learning objectives and reading route

UncertaintyLibrary 处理确定性有界假设：公差、初始状态范围、标定误差、模型差异和给定响应的比较。它既有区间与候选构造函数，也有可接线的扰动模块及依赖明确假设的解析界函数。UncertaintyLibrary handles deterministic bounded assumptions: tolerances, initial-state ranges, calibration errors, model discrepancy and comparisons of supplied responses. It includes interval and candidate functions, connected perturbation blocks and analytical bounds conditional on explicit assumptions.

本库不会自动把候选点变成一批仿真，也不会为区间自动分配概率。用户必须说明候选如何驱动本体、结果从何而来，以及结论覆盖的是有限点、采样轨迹，还是在额外数学条件下成立的区间界。The library does not automatically turn candidates into a simulation campaign or assign probabilities to intervals. Explain how candidates drive the host, where responses originate, and whether conclusions cover finite points, sampled trajectories or interval bounds under additional mathematical conditions.

本指南依据固定提交的源码编写。示例中的数值与曲线描述为源码推导的复现参考，未在本次文档工作中重新运行 Modelica 仿真。This guide documents a fixed source revision. Numerical and curve descriptions are source-derived reproduction references; Modelica simulations were not re-run during this documentation work.

02

理解元件之前，先理解这些概念Concepts to understand before using the components

区间表示范围，不表示概率分布An interval is a range, not a probability distribution

Sets.Interval(lo,hi) 表示有序闭区间。区间没有内置均匀分布、置信水平或失效率；中点只是选定代表值，不是由数据估计的期望。单位和物理含义由调用者维护。Sets.Interval(lo,hi) represents an ordered closed interval. It supplies no uniform distribution, confidence level or failure rate. Its midpoint is a selected representative, not a data-estimated expectation. The caller owns units and physical meaning.

坐标是可复现的选择规则A coordinate is a reproducible selection rule

SelectPoint 把 xi∈[-1,1] 映射到区间，-1/0/1 分别选下端、中点、上端。useCoordinateInput=false 时使用参数 xi；启用后必须连接 coordinate。时间变化坐标是显式时变输入，不是自动抽样。SelectPoint maps xi in [-1,1] into the interval; -1, 0 and 1 select lower, midpoint and upper values. With useCoordinateInput=false the parameter xi is used; otherwise connect coordinate. A time-varying coordinate is an explicit signal, not automatic sampling.

候选构造、仿真执行与响应分析是三个步骤Candidate construction, execution and analysis are separate

Grid1D、BoxCorners、CartesianGrid 只生成数值。研究者决定把这些值绑定到参数后分别仿真，或在一个模型中实例化多个本体；Analysis 处理提供的响应，不替用户补做未运行工况。Grid1D, BoxCorners and CartesianGrid generate values. The researcher binds them to separate runs or multiple host instances. Analysis operates on supplied responses; it does not execute unperformed cases.

共享坐标是依赖假设，不是统计相关估计A shared coordinate imposes dependence, not estimated correlation

SharedCoordinate 和 AffineCoordinateMap 让多项量随共同坐标变化，可以避免把物理上联动的参数任意组合。但这是一种人为选择的依赖结构，不能说它已经从数据识别了相关系数。SharedCoordinate and AffineCoordinateMap vary quantities through common coordinates and can prevent arbitrary combinations of linked parameters. This imposes a chosen dependency structure; it does not estimate a correlation coefficient from data.

观测最差值与有条件解析界不同Observed extrema and conditional analytical bounds differ

有限候选的最大值只覆盖已提供样本；EnvelopeAtSamples 只覆盖同一网格上的已有轨迹。LipschitzEnvelope 或 InterpolationErrorBounds 的结论依赖用户给定的全域导数界等条件。区间算术使用普通浮点数，并非自动提供定向舍入的严格计算证明。A finite maximum covers supplied candidates; EnvelopeAtSamples covers supplied trajectories on a common grid. LipschitzEnvelope and InterpolationErrorBounds depend on user-supplied global derivative bounds or related conditions. Interval arithmetic uses ordinary floating point rather than automatically furnishing a directed-rounding proof.

因果信号端口用于传递数值或逻辑；电气、机械、热和流体物理端口参与网络方程。不能把物理端口当作普通输入输出，也不能用一个布尔保护请求代替实际的能量或物质通路。Causal signal connectors convey values or logic. Electrical, mechanical, thermal and fluid connectors participate in network equations. A physical connector is not an ordinary signal input, and a Boolean request does not replace an energy or material path.

function AffineDiscrepancy "传播已知模型输出的缩放和偏置差异"

function CandidateExtrema "Find observed extrema and their first candidate indices"
  extends Modelica.Icons.Function;
input Real responses[:];
  input Boolean valid[size(responses,1)]=fill(true,size(responses,1));
  output Real minimum;
  output Real maximum;
  output Integer iMin;
  output Integer iMax;
  output Boolean available;
algorithm
  minimum:=0; maximum:=0; iMin:=0; iMax:=0; available:=false;
  for i in 1:size(responses,1) loop
    if valid[i] and abs(responses[i])<Modelica.Constants.inf then
      if not available or responses[i]<minimum then minimum:=responses[i]; iMin:=i; end if;
      if not available or responses[i]>maximum then maximum:=responses[i]; iMax:=i; end if;
      available:=true;
    end if;
  end for;
end CandidateExtrema;

within UncertaintyLibrary.Analysis;
block CandidateWorstCase "汇总可行的有限候选中最差观测值"
  parameter Integer n(min=1) = 3 "Number of declared candidates";
  parameter Boolean largerIsWorse = true;
  Modelica.Blocks.Interfaces.RealInput metrics[n] "Comparable metric values" ;
  Modelica.Blocks.Interfaces.BooleanInput feasible[n] "Feasibility from independent constraints" ;
  Modelica.Blocks.Interfaces.BooleanInput valid[n] "Per-candidate observation exists and is usable" ;
  Modelica.Blocks.Interfaces.BooleanInput collectionComplete "The requested evaluation stage has ended" ;
  Modelica.Blocks.Interfaces.IntegerOutput selectedIndex "1-based candidate, zero if none usable" ;
  Modelica.Blocks.Interfaces.IntegerOutput feasibleCount ;
  Modelica.Blocks.Interfaces.IntegerOutput observedCount ;
  Modelica.Blocks.Interfaces.RealOutput worstObserved ;
  output UncertaintyLibrary.Utilities.Types.EvidenceState state;
protected
  Boolean bad;
algorithm
  selectedIndex := 0;
  feasibleCount := 0;
  observedCount := 0;
  worstObserved := 0;
  bad := false;
  for i in 1:n loop
    if feasible[i] then
      feasibleCount := feasibleCount+1;
      if valid[i] then
        if noEvent(abs(metrics[i]) < Modelica.Constants.inf) then
          observedCount := observedCount+1;
          if selectedIndex==0 or (if largerIsWorse then metrics[i]>worstObserved else metrics[i]<worstObserved) then
            worstObserved := metrics[i];
            selectedIndex := i;
          end if;
        else
          bad := true;
        end if;
      end if;
    end if;
  end for;
  state := if feasibleCount==0 then UncertaintyLibrary.Utilities.Types.EvidenceState.NOT_APPLICABLE elseif bad then UncertaintyLibrary.Utilities.Types.EvidenceState.INVALID
    elseif not collectionComplete or observedCount<feasibleCount then UncertaintyLibrary.Utilities.Types.EvidenceState.UNDECIDED else UncertaintyLibrary.Utilities.Types.EvidenceState.COMPLETE;
end CandidateWorstCase;

排错、适用边界与常见误读Troubleshooting, scope and common misinterpretations

候选已经生成，为什么没有仿真结果Why are there no simulation results after creating candidates?

候选函数只返回参数数组。需要用户显式实例化本体或使用外部运行脚本，完成每个候选的仿真并保存响应；本库没有自动批处理调度器。Candidate functions return parameter arrays only. Instantiate hosts or use an external runner to execute each case and retain responses; the library contains no automatic campaign scheduler.

没有可行候选却得到数值零Why is zero returned when no candidate is feasible?

查看 available、nAccepted 和有效掩码。固定大小数组和数值字段可能含占位值；没有资格的占位零不是一个已测得的安全结果。Inspect available, nAccepted and validity masks. Fixed-size arrays and numeric fields may contain placeholders; an unavailable zero is not an observed safe result.

包络输入轨迹的时间点不一致The envelope trajectories use different time grids

先在外部建立明确、可审计的公共网格和插值规则。EnvelopeAtSamples 不会替用户自动修复错位轨迹；重采样本身也可能影响峰值。Establish an explicit auditable common grid and interpolation rule externally. EnvelopeAtSamples does not automatically repair misaligned trajectories, and resampling can itself affect peaks.

可以把界称为置信区间吗Can these bounds be called confidence intervals?

不能仅凭上下界这样表述。确定性范围、有限候选覆盖和统计置信区间有不同前提；报告时使用与实际证据一致的术语。Not merely because lower and upper endpoints exist. Deterministic bounds, finite candidate coverage and statistical confidence intervals have different assumptions; use terminology matching the evidence.

报错时先定位最小问题：加载失败、模型不平衡、初始化冲突、积分失败、输出不符合预期，是不同层次的问题。提交 issue 时给出最小模型、参数、工具版本、完整诊断和预期结果。不要用放宽容差掩盖接线或物理定义错误。Separate loading failures, structural imbalance, initialisation conflicts, integration failures and unexpected outputs. An issue should include a minimal model, parameters, tool version, complete diagnostics and expected behaviour. Do not use looser tolerances to conceal topology or physical-definition errors.
